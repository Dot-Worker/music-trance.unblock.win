# Official Monkey's Audio → synchronous WASM

Upstream 13.43 official source archive and SDK license are in `artifacts/ape`.
`prepare.py` checks pinned SHA-256 before safe extraction; `patch.py` removes worker scheduling only and excludes Linux auxv under Emscripten. No predictor/range coder/container algorithm change. The public `ape-source.tar.gz` contains only filtered original preferred C/C++/assembly source, headers, license/readme/CMake, application adapters and build/patch recipes. It excludes prebuilt DLL/LIB, project-user settings, media and the original ZIP. `.ape-source/manifest.json` authenticates each delivered original source file; `prepare.py` supports this offline source layout and applies patches once. The original ZIP remains local provenance only; official URL and SHA are recorded. BSD-3-Clause attribution/license must accompany runtime delivery.

Run `bash scripts/ape/build.sh` after the existing official Emscripten 3.1.40 toolchain is installed via the core build. Output ESM, CommonJS, identical WASM, immutable SHA manifest, full source archive. No pthreads, COOP/COEP or processing server needed. C++ gate only allows normal compression 2000; Worker validates finalized RIFF PCM WAV 16/24-bit mono/stereo, including PCM WAVEFORMATEXTENSIBLE, at most128MiB. Source conversion and any quantization are the caller's responsibility.

Initial prototype tested actual WASM under Node versus independent FFmpeg7.1.5:64/64 normal edge tests exact;18/20 broader level tests exact. Production ESM is tested by `node scripts/ape/test.mjs` against the independent own FFmpeg5.1.4 WASM:192/192 normal cases byte-exact, across44.1/48/96kHz with preserved rate/depth/channel metadata, and24-bit WAVEFORMATEXTENSIBLE. 24-bit Insane failed and is deliberately unavailable. This is not a claim of all upstream codec configurations. Browser Worker and independent application-core roundtrips must be verified before release.

The JS adapter `encodeApe(wavBytes,{signal,onStatus,coreURL,wasmURL})` starts a fresh module Worker, imports ESM coreURL, loads wasmURL, encodes normal2000, returns Uint8Array, and terminates the Worker on completion/cancellation/error. Limits and integer format validation are in `src/audio/ape-wav.js`.

Sanitized-delivery verification: the public source archive was extracted into an empty build root with no original SDK ZIP. `prepare.py` accepted its per-file manifest, patches applied once, and rebuilding produced byte-identical `ape.wasm` and `ape.js` compared with the production artifacts. The archive was audited to contain no `.dll`, `.lib`, `.exe`, `.zip`, `.user` or `.wav` files.

Official download compatibility: `download.py` identifies the source build with an explicit, truthful User-Agent and accepts ZIP/octet-stream content. The vendor returned406 to Python's default agent but200 for this declared client; the successful response matched the pinned SHA. Only transient transport errors and HTTP408/429/500/502/503/504 get up to3 attempts; authorization/denial/406 errors, redirects, oversized content and checksum failures fail closed. Verified bytes are committed atomically. Run `python3 scripts/ape/test-download.py` for downloader regression tests.
